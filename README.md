# Print Tech Catalog — Gemini version

The same product catalog as `print-tech-catalog`, rebuilt by Google Gemini
from the same brief (RTL Arabic, mobile-first, silver + kiwi + white,
57 products, search, filters, favorites, lightbox, deep links).

The page fetches its data live from
`https://1tarekdesign-web.github.io/print-tech-catalog/catalog.json`,
so both sites always show the same products and prices.

Small fixes applied after Gemini's build (see `gemini-version/` for the
original file): lightbox "Next" button bug, sticky filter bar alignment,
footer logo in color, multi-image thumbnails in the lightbox, keyboard arrows.
